# Multisite network

## The free plugin on multisite

Lumtera works on multisite, activated network-wide or on individual sites. Each site has its own results, settings and report. When you uninstall it, its data is removed from every site in the network. See [Data & uninstall](/developers/data).

## One license for the network <span class="pro-pill">Pro</span>

If Lumtera Pro is **network-activated**, one license covers every site in the network, using a single site activation for the network's main address.

<ol class="step-list">
  <li>Go to <span class="screen-path">Network Admin → Accessibility → License</span>.</li>
  <li>Enter your license key and click <strong>Activate</strong>.</li>
</ol>

Each site's <span class="screen-path">Accessibility → Settings → License</span> tab shows a read-only summary: *"This network's license is managed by the network administrator."* If the main site already had a license before you network-activated Pro, it's adopted as the network license automatically.

If Pro is activated on individual sites instead, each site needs its own license activation.

## Network overview <span class="pro-pill">Pro</span>

<div class="pro-callout">The network overview is included in the <strong>Agency</strong> and <strong>Unlimited</strong> plans.</div>

<span class="screen-path">Network Admin → Accessibility</span> lists every site in the network with its **Score**, **Errors**, **Needs review** and **Checked** count, worst first. Search for a site by name, and use **Open overview** to go to that site's Lumtera screens to scan it or see its issues.

Sites where Lumtera isn't active, or that haven't been scanned yet, say so in the table.

For client sites that aren't in your network, use the [Agency portfolio](/pro/portfolio).
