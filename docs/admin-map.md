# Your WordPress admin

Lumtera adds one top-level menu, **Accessibility**, plus a few things inside screens you already use. This page maps each one to its guide.

## The Accessibility menu

The menu shows a red badge with the number of items that have at least one error, including drafts and scheduled posts. Every Lumtera screen has the same row of tabs at the top, so you can move between them.

"Report roles" below means the roles allowed to **See reports and check the site** under <span class="screen-path">Accessibility → Settings → Permissions</span>. By default, that's editors and administrators. See [Roles & permissions](/permissions).

| Menu | What it's for | Who can open it | Guide |
| --- | --- | --- | --- |
| **Overview** | Site-wide score, errors, the same issue on many pages, the most common issues, and **Check all content** | Report roles | [Site report](/site-report#overview) |
| **Content** | Every checked post and page, worst first, or the same issue grouped across pages, with filters | Report roles | [Site report](/site-report#content-report) |
| **Alt text** | Describe Media Library images and add the text to posts | Anyone who can upload files (authors and up) | [Alt text manager](/alt-text) |
| **Statement** | Create a draft accessibility statement page | Anyone who can publish pages (editors and administrators) | [Accessibility statement](/statement) |
| **Settings** | What gets checked, how strict to be, AI, site fixes, permissions and the weekly email | Administrators | [Settings](/settings) |
| **Free vs Pro** | Compares the free plugin with Pro plans. Hidden once Pro is installed. | Report roles | [What Pro adds](/pro/) |

Without Pro, **Page checks**, **Documents**, **Fixes**, **Activity**, **Reports** and **Portfolio** appear with a "Pro" badge. They describe what each Pro feature does. Nothing you already use is locked. With Pro, they become the real screens. See [What Pro adds](/pro/).

## Inside the editors

| Where | What | Guide |
| --- | --- | --- |
| Block editor, top toolbar | Lumtera icon: opens the **Accessibility** sidebar. The icon gets a colored dot when there are errors or items to review. Also in the Options menu as **Accessibility checker**. | [Block editor sidebar](/block-editor) |
| Block editor, post settings sidebar | **Manual accessibility checks** panel: nine guided checks with results saved on the post | [Guided manual checks](/manual-checks) |
| Block editor, pre-publish panel | **Accessibility** summary before publishing | [Before publishing](/block-editor#before-publishing) |
| Image block settings | **Accessibility** panel: decorative switch and **Suggest alt text** | [Decorative images](/block-editor#decorative-images) |
| Elementor editor | Floating **Accessibility** button and panel | [Elementor](/page-builders#elementor) |
| Classic editor | **Accessibility check** box below the content | [Classic editor](/page-builders#classic-editor) |

Divi, Beaver Builder, Bricks, Oxygen and WPBakery don't get a panel inside the builder, but their pages are checked and Lumtera's links open them in the builder. See [Other page builders](/page-builders#other-page-builders).

## Elsewhere in WordPress

| Where | What | Guide |
| --- | --- | --- |
| Admin bar, on a published page | **Accessibility**: opens review mode on the live page. Shown to roles allowed to review pages (by default, anyone who can edit posts), on posts they can edit. | [Review mode](/review-mode) |
| Posts, Pages and Products lists | **Accessibility** column with each item's status and score. Sortable by score. | [Site report](/site-report#the-accessibility-column) |
| Dashboard | **Accessibility** widget with your score and the pages that need attention. Shown to report roles. | [Site report](/site-report#dashboard-widget) |
| Users | **Lumtera Reporter** role, for agency hubs | [Roles & permissions](/permissions) |
| Tools → Export / Erase Personal Data | Lumtera's dismissals, accepted AI alt text and manual check results | [Data & uninstall](/developers/data) |

Who can see what is covered in [Roles & permissions](/permissions).
