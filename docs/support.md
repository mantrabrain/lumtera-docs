# Support

## Lumtera (free)

Ask on the [Lumtera support forum on WordPress.org](https://wordpress.org/support/plugin/lumtera/). There's also a **Support** link next to Lumtera on your <span class="screen-path">Plugins</span> screen.

## Lumtera Pro

For help with Pro, [contact MantraBrain](https://mantrabrain.com/contact/) and mention your license key's email address. You can manage your license, downloads and invoices in your [store account](https://store.mantrabrain.com/account/).

## What to include

The fastest way to a fix is a report we can reproduce:

- Your Lumtera version, and Lumtera Pro's if you use it (<span class="screen-path">Plugins</span> screen).
- Your WordPress and PHP versions (<span class="screen-path">Tools → Site Health → Info</span>).
- The theme and page builder you use.
- Which optional features are on: [site fixes](/site-fixes), [AI suggestions](/ai) (and which AI provider), and any changes under [Permissions](/permissions).
- For a wrong result: the check's ID (for example `link-ambiguous-text`, see [All checks](/checks)) and a small piece of HTML or a block that triggers it. `wp lumtera check` is a quick way to test HTML on its own. See [WP-CLI](/developers/wp-cli).
- For an error: the message on screen, and anything in your PHP error log from the same moment.

Before you write, [Troubleshooting](/troubleshooting) and the [FAQs](/faqs) cover the most common questions.

## Report a security issue

Please don't post security issues on the public forum. [Contact MantraBrain](https://mantrabrain.com/contact/) privately instead.
